01 // TENTANG SAYA

Dari Jaringan Fisik hingga Arsitektur Cloud Modern

Menghubungkan rekayasa jaringan level rendah dengan sistem terdistribusi yang tangguh, perdagangan otonom, dan grafis web interaktif modern.

+-- --+ +-- --+
PENDIRI · CODAXIOM PANCORAN, JAKARTA SELATAN · 6.26° S, 106.83° E

Saya membangun perangkat lunak dari lapisan terdalam — dari server Linux dan perangkat jaringan fisik hingga platform full-stack modern dan sistem AI percakapan.

Fondasi saya bermula dari Teknik Komputer dan Jaringan (TKJ) di SMK Pembina Bangsa: crimping kabel Ethernet, konfigurasi router Mikrotik, mengelola server Linux bare-metal, dan menganalisis packet loss pada lapisan fisik. Bekerja langsung dengan perangkat keras memberi saya pemahaman sejak dini bahwa setiap abstraksi kode memiliki batasan fisik yang nyata.

Melanjutkan studi Sistem Informasi di Universitas Bakrie (saat ini semester 7) memperluas fondasi tersebut ke basis data relasional, arsitektur terdistribusi, dan sistem GIS spasial. Saya mendirikan Codaxiom untuk mewujudkan rekayasa tersebut menjadi perangkat lunak produksi nyata: platform perdagangan otonom, agen AI cerdas, dan sistem web berkinerja tinggi.

Prinsip Utama Rekayasa

01. Kesederhanaan Radikal

Hilangkan kompleksitas yang tidak perlu. Arsitektur tangguh dan rekayasa platform native selalu mengungguli dependensi yang rapuh.

02. Integritas Mutlak

Transaksi atomik dan nol kehilangan data sejak desain awal. Sistem produksi membutuhkan status yang terverifikasi dan tanpa metrik fiktif.

03. Kedaulatan Sistem

Pemahaman menyeluruh dari tingkat fisik server Linux dan jaringan hingga grafis 3D interaktif berakselerasi GPU.
