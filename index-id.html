01 // LATAR BELAKANG & FONDAKSI

Saya memulai dari kabel dan router fisik sebelum membangun aplikasi web.

Fondasi saya bermula dari bengkel laboratorium SMK (TKJ di SMK Pembina Bangsa): crimping kabel Ethernet Cat6, konfigurasi firewall MikroTik, dan instalasi server Linux. Bekerja langsung dengan perangkat keras memberi saya pemahaman praktis tentang jaringan, batasan memori, dan batas kerja sistem di bawah lapisan abstraksi perangkat lunak.

Di Universitas Bakrie (saat ini semester 7 Program Studi Sistem Informasi), saya menghubungkan fondasi fisik tersebut dengan ilmu komputer formal: arsitektur basis data relasional, konkurensi sistem terdistribusi, dan algoritma WebGIS spasial.

Melalui Codaxiom, saya menerapkan disiplin menyeluruh tersebut pada sistem produksi nyata, termasuk platform web multi-tenant, otomatisasi alur kerja WhatsApp bisnis, dan antarmuka web 3D yang responsif.

Saya berkomunikasi dan menulis dalam bahasa Inggris secara lancar untuk arsitektur teknis, koordinasi tim async, dan walkthrough proyek klien internasional — memungkinkan kolaborasi lintas zona waktu berjalan tanpa hambatan.
