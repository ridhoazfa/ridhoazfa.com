ENGINEERING BACKGROUND

I started with physical cables and routers before building web applications.

My foundation started in a vocational high school lab (TKJ at SMK Pembina Bangsa), crimping Cat6 Ethernet cables, configuring MikroTik firewalls, and setting up Linux servers. Working directly with hardware gave me a practical understanding of networking, memory constraints, and system limits beneath software abstractions.

At Universitas Bakrie (currently in my 7th semester of Information Systems), I connected that physical groundwork with formal computer science: relational database architecture, distributed concurrency, and spatial WebGIS algorithms.

Through Codaxiom, I apply that end-to-end discipline to production systems, including multi-tenant web platforms, automated WhatsApp commerce workflows, and responsive 3D web interfaces.

Core Work Principles

01. Lean Dependencies

Rely on native platform features and standard libraries before pulling in third-party packages. Less bloat means faster load times, easier maintenance, and fewer vulnerabilities.

02. Data Reliability

Design data flows and transactions defensively. Whether managing orders, webhooks, or database mutations, states are explicit and verified to prevent data loss.

03. End-to-End Execution

Take responsibility for the full cycle: configuring Linux servers and reverse proxies on the backend, while crafting responsive, polished interfaces on the frontend.
